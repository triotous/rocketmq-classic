# Compatibility fixtures

`remoting/` contains Java 5.5.1-generated offline command frames and JSON metadata. Each metadata file identifies the 5.5.1 Java client, 5.3.4 target server baseline (not a claim that a server was contacted), scenario, codec, code, semantic fields, body length, SHA-256 and regeneration command. Phase 2 adds transaction, request/reply, large private-code, and FastCodesHeader optimized/ordinary codec fixtures, plus both serialization paths for the original cases. `remoting/rust-generated/` contains Rust-generated frames decoded during Maven verify using the pinned Java client. Phase 8 adds `messages/records.json`, generated and decoded by Java 5.5.1; it contains bounded message-record bytes and decoded field/ID expectations. The generator is `compat.MessageDecodeFixtures`; `mvn -f compat/java-reference/pom.xml exec:java -Dexec.args='message-decode-fixtures --output fixtures/messages/records.json false'` regenerates it and Maven verify rejects drift. Its provenance records source commit `efa1be59d6fc747ad220f036c86030f05f0419f9`, and its SHA-256 is in `docs/compatibility/P8_MESSAGE_FIXTURE_SHA256SUMS.txt`. Phase 8 source mappings and decoder/pull-result evidence are in `docs/compatibility/PHASE_8_OFFLINE_METHOD_MATRIX.md`. Live scenarios remain pending Phase 19. The remoting TLS test fixtures under `crates/rocketmq-classic-remoting/tests/fixtures/tls/` include Java 5.5.1's encrypted PBES2 + 3DES private key (`privkey.pem`, password `1234`) and matching test certificate (`ca.pem`), copied from the pinned read-only Java reference checkout's `remoting/src/test/resources/certs/`. They are test-only credentials and must not be used for real services; the focused Rust test verifies decryption, identity matching, rustls loading, and incorrect-password rejection.

Regenerate with `mvn -f compat/java-reference/pom.xml verify` followed by `mvn -f compat/java-reference/pom.xml exec:java -Dexec.args='fixtures --output fixtures/remoting'`. Run `python3 tests/differential/compare.py --self-test` to validate the comparator. Fixture bytes are generated deterministically with fixed opaque/version/fields; live interaction evidence is tracked separately in `tests/differential/scenarios.yaml` and remains pending Phase 19.
